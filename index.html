3. Apotek Digital

Proyek ini merupakan sistem informasi apotek berbasis web yang dikembangkan menggunakan PHP, MySQL, dan CSS. Sistem ini dirancang untuk mengelola data obat, resep digital, transaksi penjualan, serta data pasien secara terintegrasi. Terdapat dua portal utama yaitu Portal Admin untuk apoteker dan staf dalam mengelola operasional apotek, serta Portal Pasien untuk melihat resep, memesan obat, dan riwayat pembelian. Dibangun dengan tampilan modern, responsif, dan ramah pengguna.

4. Sirantrean Gikara
Sistem Antrian Klinik

Proyek ini merupakan aplikasi web Sistem Antrian Klinik yang dikembangkan sebagai bahan praktik menggunakan framework Laravel. Aplikasi ini mensimulasikan alur antrian pasien secara digital, mulai dari reservasi online, check-in, pemanggilan antrian, hingga pengambilan obat di apotek. Dilengkapi dengan fitur multi-role untuk admin, apoteker, dan super admin, serta tampilan display antrian real-time untuk monitor klinik. Dibangun dengan pendekatan modern menggunakan Tailwind CSS dan Vite.

Proyek ini hanya dibuat untuk keperluan pembelajaran dan tidak dipublikasikan secara online.
